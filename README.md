# Crop Prediction for Aurar Agri-Culture

## Project Overview

This project focuses on developing a machine learning-based crop recommendation system for Aurar Agri-Culture. It uses soil and weather conditions to predict the most suitable crop for cultivation, helping farmers make informed decisions and improve agricultural productivity.

## Objectives

- Analyse soil and weather conditions affecting crop selection.
- Identify relationships between environmental factors and crop recommendations.
- Develop and compare multiple machine learning classification models.
- Evaluate model performance and identify the most accurate model.
- Explore how predictive analytics can support smarter farming decisions.

## Methodologies & Frameworks

- Data Preprocessing and Normalisation
- Logistic Regression
- K-Nearest Neighbour (KNN)
- Support Vector Machine (SVM)
- Naive Bayes
- Decision Tree
- Random Forest
- 10-Fold Cross-Validation

## Analytics Applications

- Crop Recommendation and Prediction
- Soil Nutrient Analysis (N, P, K)
- Weather Condition Analysis
- Machine Learning Model Comparison
- Agricultural Decision Support

## Tools & Technologies

- Orange Data Mining
- Kaggle Crop Recommendation Dataset

## Key Findings

Random Forest achieved the highest accuracy of approximately 99.6%, outperforming the other five models. The results demonstrated how machine learning can help farmers select suitable crops based on soil and climatic conditions.
